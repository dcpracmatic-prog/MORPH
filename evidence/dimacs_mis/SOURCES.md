# DIMACS instances — provenance

Source: DIMACS Implementation Challenge (2nd) clique benchmark graphs,
Glasgow mirror: https://www.dcs.gla.ac.uk/~pat/maxClique/distribution/DIMACS_cliques/
Downloaded 2026-11-23. Files are used as-is (edge lists as given) as MIS
instances, the same convention as the QOBLIB MIS set in this repo
(e.g. brock200_1 there is also used as an MIS instance, not complemented).
Published maximum-clique optima for these graphs therefore do NOT apply
to the MIS sizes reported here; no optimality claim is made.
SHA-256 checksums: see SHA256SUMS.txt in this directory.
Files: brock200_1, brock200_2, brock400_1, c-fat200-1, c-fat200-5,
c-fat500-1, hamming8-4, keller4, MANN_a9, p_hat300-1, p_hat300-2,
